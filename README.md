**Junior Academic Quizbook** is a lightweight, responsive, single-file HTML5/JavaScript web application built to help Junior Secondary School students (JSS 1 to JSS 3 / Basic 7 to Basic 9) practice, evaluate, and excel in their core academic and national entrance exams.

Designed with an animated glassmorphism UI, gradient background animations, and custom modal components, this application runs **100% offline** in any standard web browser without server installations or external library dependencies.

---

## 🌟 Key Features

- **Single-File Architecture:** The entire app—including styles, UI logic, custom dialog overlays, and the massive question bank—is cleanly contained within a single standalone `.html` file for zero-friction distribution (via flash drive, local networks, or web hosting).
- **Glassmorphism UI Design:** Modern translucent card layout (`backdrop-filter: blur`), animated linear gradient backgrounds, and responsive layouts tailored for mobile phones, tablets, and desktop displays.
- **Robust CBT Engine:**
  - Candidate registration modal with personalized student greeting.
  - Interactive **30-minute exam countdown timer** with automated submission handling upon expiry.
  - Dynamic **question and option shuffling** per test session to guarantee unique practice runs.
  - Live progress tracking bar and real-time score counters.
- **Instant Academic Evaluation:** Automated grading upon submission, featuring tier-based academic feedback and performance scaling (Excelsior, Great Job, Keep Practicing).
- **Fallback In-App Dialogs:** Custom-styled modal overlays designed to replace native browser `alert()` and `confirm()` popups, ensuring flawless behavior in restricted browser environments.
